# Add offline profiles with a local skin and cape wardrobe

Create an offline profile during onboarding or in account settings, and keep
offline profiles usable after removing the last Microsoft account. The first
offline profile becomes the default account. Authenticated servers and Microsoft
services still require a valid Microsoft account.

Offline profiles can import skin and cape PNGs or look up a skin by username.
The custom Windows build includes the 1.8.9 Ornithe wardrobe component so the
appearance applies in-game and can also be changed from the in-game wardrobe.
